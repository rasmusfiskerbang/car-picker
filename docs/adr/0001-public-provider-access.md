# Collect public first-party facts unless explicitly prohibited

The owner-operated comparison may collect minimized, attributed offer facts from
public first-party pages and same-provider APIs used by those pages unless an
applicable robots rule, published term, technical access control, rate limit, or
provider instruction explicitly prohibits it. This chooses bounded public access
over requiring affirmative written permission while preserving source ownership,
low request volume, content minimization, and prompt owner-controlled blocking
when a provider asks collection to stop.

The decision does not authorize authentication bypass, bot-challenge evasion,
identity rotation, unrelated crawling, personal or accidentally exposed data, or
third-party endpoints merely because a provider page embeds them. Ambiguous
restrictions pause that provider for owner review. Each provider source audit
records its exact boundary, last policy check, applicable restrictions, and access
decision; material source or terms changes, access failures, and provider contact
trigger revalidation.
