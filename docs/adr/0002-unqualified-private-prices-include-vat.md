# Treat unqualified private-consumer prices as VAT-inclusive

When a first-party source explicitly offers an amount to a private individual,
the catalogue treats that amount as VAT-inclusive if the provider gives no VAT
qualifier. Danish consumer prices are required to include VAT, so requiring the
provider to repeat “inkl. moms” would quarantine otherwise explicit consumer
offers without improving the prospective lessee's understanding. Explicit
excluding or contradictory VAT wording takes precedence, remains visible, and
blocks admission; the rule never converts a stated net amount.

This decision uses the consumer context as a normalization rule while retaining
the provider's exact price wording as source evidence. It follows the official
consumer guidance that consumer prices must include VAT:
<https://forbrug.dk/emner/penge-og-forsikring/priser-tilbud-og-gebyrer>.
